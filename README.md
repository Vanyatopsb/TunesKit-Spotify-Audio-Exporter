## 🧭 Getting Started

The journey is short — the destination is a library that feels like yours.

1. **Open the studio.** Launch the app from the Start menu or the pinned taskbar tile.
2. **Point to a workspace.** Choose a root folder where your archive will live. TuneVault creates sub-shelves automatically.
3. **Sign in to your listener profile (optional).** This is a local profile, not a cloud account — it stores theme and preset preferences.
4. **Import a playlist or a link.** Paste it, drag it in, or pick from the built-in discovery pane.
5. **Choose an export profile.** Hi-Fi, Portable, Commute, or your own custom recipe.
6. **Watch the shelves fill up.** Progress is streamed live per track, with a running log you can filter.
7. **Browse the local index.** Search by artist, album, mood tag, or year.
8. **Fine-tune the metadata.** Bulk-edit artists, fix casing, and pull in missing artwork.

No account walls, no nags, no surprise windows. Just a studio that respects your time.

## 🧱 Architecture Overview

TuneVault Resonance Studio is built around four cooperating services.

- **The Director** — a lightweight coordinator that owns the main window, decides what the user sees, and delegates work.
- **The Librarian** — a metadata and index engine. It parses tags, reads release info, stores records in a local SQLite index, and answers search queries.
- **The Shelver** — the file-system organizer. It knows how to lay out folders based on a profile, and it validates every path before writing.
- **The Stagehand** — the audio pipeline. It handles decoding, optional normalization, and final encode. It runs in an isolated sandbox that gets torn down between jobs.

Everything communicates over a local, single-user IPC bus. Crashes are contained; the Director notices and restarts the affected service without losing your session.

## 🧯 Troubleshooting Notes

- **Interface feels cramped on a small screen.** Switch to the Compact layout in the View menu.
- **Locale not applied after changing.** Check the "Pin locale" flag — it can lock the interface to one language.
- **Export folder locked by another app.** Close any app that watches that folder (cloud sync clients are frequent offenders).
- **Metadata missing after export.** Re-scan the folder and re-run the tag pass; occasionally a file system may not flush attributes immediately.
- **Slow index rebuild.** Confirm the catalog is stored on an SSD. Mechanical drives are supported but slow.
